# Applied AI Engineering Portfolio

Repositório oficial do portfólio pessoal e sistemas de Inteligência Artificial aplicada desenvolvidos por Américo Souza.

## 🛠️ Stack Tecnológica
* **Linguagem:** Python
* **Deep Learning & Frameworks:** PyTorch, Hugging Face (Transformers)
* **Busca Vetorial & RAG:** FAISS (Indexação Euclidiana L2), Embeddings Densos, Qwen2.5
* **NLP & Classificação:** mDeBERTa (Zero-Shot Classification)
* **Deploy & Ferramentas:** Google Colab, Git, GitHub Pages

---

## 📂 Projetos no Portfólio

1. **Delivery Operations RAG**
   - **Descrição:** Sistema de consulta semântica automatizada para regras corporativas e manuais logísticos utilizando recuperação vetorial (FAISS) e LLMs open-source com restrição estrita de contexto para mitigação de alucinações.
   
2. **Delivery Intent Classifier**
   - **Descrição:** Classificador de intenções corporativas baseado em modelos multilíngues NLI (mDeBERTa) para triagem e roteamento inteligente de chamados de suporte.

3. **Delivery Sentiment Analyzer**
   - **Descrição:** Pipeline de Deep Learning para análise de polaridade em avaliações de clientes com extração de scores de confiança e métricas de satisfação.
